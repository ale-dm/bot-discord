# Features

Las ideas de funcionalidad nueva que vivían en este archivo se migraron a
[GitHub Issues](https://github.com/ale-dm/bot-discord/issues?q=is%3Aopen+label%3Afeature-idea)
el 2026-10-06 (label `feature-idea`), con un issue por idea y labels de categoría
(`apuestas`, `duende-ia`, `plex-seerr`, `economia`, `administracion`) y esfuerzo
(`esfuerzo-S`/`esfuerzo-M`/`esfuerzo-L`: S = reutiliza algo que ya existe, una tarde ·
M = un par de días · L = más). Las 4 marcadas con `prioridad` eran las de "por dónde
empezar".

Cuando se haga una, se cierra su issue (desde el PR, con "Closes #N") y se apunta en
[CHANGELOG.md](../CHANGELOG.md), igual que antes. Los problemas del código que ya
existe siguen en [DEUDA_TECNICA.md](DEUDA_TECNICA.md), y las tareas manuales en
[TAREAS.md](TAREAS.md).

Este archivo se deja como redirección; las ideas ya no se mantienen aquí.
